# Igor Babler — Portfolio

Personal portfolio developed to showcase projects, skills, and professional journey in an immersive and interactive way.

## 🚀 Features

- **Frame animation** — Image sequence synchronized with the user's scroll, simulating a notebook opening
- **Smooth transition** — Automatic transition between the Hero and About Me sections with a gradient effect
- **Multilingual system** — Support for 4 languages (Portuguese, English, Spanish, and Swedish) with dynamic switching and persistence via LocalStorage
- **Enter Button** — Translucent button that starts the background music and performs automatic scroll to the About Me section
- **Music Player** — Music player with play/pause controls, interactive progress bar, and automatic playback
- **Scroll animations** — Texts animated with lateral entry and blur, controlled by GSAP ScrollTrigger
- **Glass background** — Frosted glass effect on paragraphs with backdrop-filter and subtle gradients
- **Projects gallery** — Carousel with square videos, navigation arrows, and dot indicators
- **Project detail** — Individual tab for each project with title, technologies, image, and full description in multiple languages
- **Dynamic header** — Header that changes style (transparent → solid) based on scroll progress
- **Galaxy background** — Looping background video in the projects section with dark overlay
- **Cardboard divider** — Transition image between the yellow section and the projects section, with Z-axis overlapping
- **Contact footer** — Final section with partnership text and direct LinkedIn link
- **Responsive** — Layout adapted for desktop and mobile with optimized breakpoints

## 🛠️ Technologies

### Frontend
- **HTML5** — Semantic structure
- **CSS3** — Styling with CSS variables, gradients, backdrop-filter, animations, and media queries
- **JavaScript** — Interaction logic, media control, and DOM manipulation

### Libraries
- **GSAP 3.12.5** — Animations and scroll control
  - **ScrollTrigger** — Scroll-linked animations
  - **ScrollToPlugin** — Programmatic smooth scrolling

### Fonts
- **Archivo Black** — Titles and headings
- **Manrope** — Body text and interface

### Media
- **MP4/WebM Videos** — Animation frames, gallery background, and project cards in 1:1 format
- **MP3 Audio** — Ambient soundtrack
- **PNG Images** — Dividers, visual assets, and project images

### Tools
- **Git** — Version control
- **GitHub Pages** — Hosting
- **After Effects** — Creation of raw videos and animations
- **FFmpeg / Kapwing** — Video conversion and editing
